## Loupe · 览 1.0.0

第一个公开版本：一个窗口看清各种文件的 macOS 原生查看器。

- **文本与代码**：自动识别编码（UTF-8 / GBK / GB18030 / Big5 / Shift_JIS / UTF-16…），语法高亮，大文件秒开；Markdown 可编辑。
- **文档**：PDF、Word、PowerPoint、iWork（系统快速查看，装有 iWork 时导出完整预览）、本地网页（脚本在受限环境里运行）。
- **表格**：xlsx / ods / csv / Numbers 按原格式显示；表上的图表（柱、条、折线、面积、饼、环形、散点、雷达、气泡、组合图）、图片、形状、文本框和整页图表都画出来；一格之内分段的字色、加粗、字号也保留。公式计算框支持约 90 个函数和跨文件引用。
- **图片、音视频、压缩包、字体**：常见格式都能直接看；mpv 可选，用来播放系统不支持的视频。
- **AI 助手（可选）**：本地模型或云端服务二选一，能读文件、精确计算、生成 Word / Excel / PDF。

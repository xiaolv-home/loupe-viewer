# 数据分析报告

目标：一份**拿去就能用**的 Word 报告。读者只看第一页也能知道“发生了什么、为什么、该做什么”。

## 步骤

1. **弄清数据**：`sheet_overview`；确认时间范围、口径（金额含税否、是否含退款、门店范围）。口径不清时在报告“数据说明”里写明假设。
2. **算指标**（全部用工具）
   - 总量：合计、笔数、均值（`calculate`）。
   - 结构：按 2–3 个关键维度 `summarize`（地区、品类、渠道、时间），记下前 3 / 后 3 和占比。
   - 变化：有两期数据时算环比/同比（`add_column` 增长率），找出变化最大的项。
   - 异常：明显偏离的项（增长/下降超过 30%、负值、空缺）。
3. **找原因**：对变化最大的项再下钻一个维度（例如华东下降 → 华东按门店再 `summarize`），用数据说明是哪几个子项带来的。
4. **写报告**：用 `write_file` 生成 `.docx`（文件名如「2026年9月销售分析报告.docx」），Markdown 写法，结构如下。
5. **附表**：报告用到的汇总表用 `summarize` 的 `save_as` 或 `create_spreadsheet` 存成同名“_数据附表.xlsx”。

## 报告结构（Markdown）

```
# {主题}分析报告（{时间范围}）

## 一、核心结论
- 3 条以内，每条一句话 + 一个关键数字，如：**9 月实收 1,284.6 万元，环比 -6.2%**，主要因华东区 3 家门店闭店。

## 二、关键指标
| 指标 | 本期 | 上期 | 变化 |
| --- | --- | --- | --- |

## 三、分维度表现
### 按{维度一}
（表格 + 2–3 句解读：谁最好、谁最差、差距多大）
### 按{维度二}

## 四、问题与原因
1. 问题 —— 数据证据 —— 原因判断（标明是数据直接显示还是推测）

## 五、建议
1. 具体可执行的动作 + 预期影响 + 建议负责方

## 数据说明
数据来源文件、时间范围、口径、剔除了哪些行、尚存的数据质量问题。
```

## 质量标准

- 每个数字可追溯到工具计算；表格里的数字与正文一致。
- 结论具体（有对象、有数字、有方向），不写“整体表现良好”这类空话。
- 推测要标注“推测”；数据不足以支持的结论不写。
- 一般 2–4 页，图表用表格代替。

# 数据质量检查：〔库名.表名〕

## 主键唯一

```sql
SELECT 〔主键字段〕, COUNT(*) AS cnt
FROM 〔库名.表名〕
WHERE 〔日期字段〕 = '〔日期〕'
GROUP BY 〔主键字段〕
HAVING COUNT(*) > 1;
```

## 必填字段空值

```sql
SELECT COUNT(*) AS 总行数,
       SUM(〔字段〕 IS NULL) AS 空值数
FROM 〔库名.表名〕
WHERE 〔日期字段〕 = '〔日期〕';
```

## 行数和金额波动

```sql
SELECT 〔日期字段〕, COUNT(*) AS 行数, SUM(〔金额字段〕) AS 金额
FROM 〔库名.表名〕
WHERE 〔日期字段〕 >= '〔开始日期〕'
GROUP BY 〔日期字段〕
ORDER BY 〔日期字段〕;
```

## 和上游对账

```sql
SELECT 'source' AS 来源, SUM(〔金额字段〕) AS 金额 FROM 〔上游表〕 WHERE 〔日期字段〕 = '〔日期〕'
UNION ALL
SELECT 'target', SUM(〔金额字段〕) FROM 〔库名.表名〕 WHERE 〔日期字段〕 = '〔日期〕';
```

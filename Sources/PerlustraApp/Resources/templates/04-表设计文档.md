# 表设计：〔库名.表名〕

| 项目 | 内容 |
|---|---|
| 中文名 | 〔表中文名〕 |
| 分层 | 〔ODS / DWD / DWS / ADS / DIM〕 |
| 主题域 | 〔主题〕 |
| 负责人 | 〔姓名〕 |
| 创建日期 | 〔今天〕 |

## 用途

〔这张表解决什么问题？谁会用？〕

## 粒度

**一行代表：**〔一个门店一天一个渠道〕

主键：〔字段1, 字段2〕

## 字段

| 字段 | 类型 | 可空 | 说明 | 来源 |
|---|---|---|---|---|
| 〔dt〕 | 〔DATE〕 | 否 | 业务日期 | 〔来源表.字段〕 |
| 〔字段名〕 | 〔类型〕 | 〔是 / 否〕 | 〔说明〕 | 〔来源表.字段〕 |
| 〔字段名〕 | 〔类型〕 | 〔是 / 否〕 | 〔说明〕 | 〔来源表.字段〕 |

## 上下游

- 上游：〔来源表〕
- 下游：〔使用它的表或报表〕

## 更新方式

- 调度：〔工作流名称，每日 几点〕
- 写入方式：〔全量覆盖 / 按日分区覆盖 / 增量合并〕
- 回刷窗口：〔最近几天〕

## 分区与索引

- 分区：〔字段〕
- 索引：〔字段〕
- 预计数据量：〔每日 x 万行〕
- 保留时长：〔多久〕

## 建表语句

```sql
CREATE TABLE 〔库名.表名〕 (
  〔字段名〕 〔类型〕 COMMENT '〔说明〕',
  PRIMARY KEY (〔字段1, 字段2〕)
) COMMENT='〔表中文名〕';
```

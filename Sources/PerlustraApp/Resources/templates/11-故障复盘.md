# 故障复盘：〔故障名称〕

| 项目 | 内容 |
|---|---|
| 发生时间 | 〔日期 时间〕 |
| 恢复时间 | 〔日期 时间〕 |
| 级别 | 〔P0 / P1 / P2〕 |
| 复盘人 | 〔姓名〕 |
| 复盘日期 | 〔今天〕 |

## 一句话总结

〔什么原因导致什么结果，影响了多久。〕

## 影响

- 影响的数据：〔表和日期范围〕
- 影响的报表和人：〔谁看到了错数〕
- 是否影响决策：〔是 / 否，说明〕

## 时间线

| 时间 | 发生了什么 |
|---|---|
| 〔时间〕 | 〔发现异常，怎么发现的〕 |
| 〔时间〕 | 〔定位过程〕 |
| 〔时间〕 | 〔修复并恢复〕 |

## 根因

- 直接原因：〔哪一步出错〕
- 根本原因：〔为什么会出错〕
- 为什么没有提前发现：〔监控缺什么〕

## 修复

- 处理方式：〔怎么修的〕
- 补数范围：〔日期范围〕
- 验证方式：〔怎么确认修好了〕

|---|---|---|---|

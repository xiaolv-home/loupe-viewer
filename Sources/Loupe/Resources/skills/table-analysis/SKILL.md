# 表格分析

目标：让用户拿到**算准了的结论**和**能直接用的结果表**，而不是对表格内容的复述。

## 工作流程

1. **体检**（必做）
   - `sheet_overview` 看清：有几张表、表头在第几行、每列是什么（数字/文字/日期）、数据从第几行到第几行。
   - 表头不在第 1 行、有合并单元格、有“合计”行混在数据里时，要在结论里说明，并在计算时排除合计行（例如用 `where_column` 过滤或用 `COUNTIFS` 排除）。
2. **数据质量**（数据量 > 20 行时做）
   - 行数：`calculate` `COUNTA(A:A)`（减去表头）。
   - 空值：每个关键列 `COUNTBLANK(B2:B{末行})`。
   - 重复：对疑似主键列用 `summarize` 的 `aggregate=count` 按该列分组，计数 > 1 的就是重复。
   - 异常值：数值列算 `MIN`、`MAX`、`AVERAGE`、`MEDIAN`；明显离群（负数、超过均值 5 倍、日期越界）的用 `filter_view` 筛出来给用户看，或 `select_cells` 指出位置。
3. **核心分析**（按用户的问题）
   - 分组汇总：`summarize`（group_by 分类列，values 数值列，aggregate=sum/average/count）。结果已按第一项降序，可直接说出前几名和后几名。
   - 占比：总计行 ÷ 各组；或 `add_column` 加“占比”列（如 `=C2/SUM(C:C)`）。
   - 对比/增长：两列（如本月、上月）用 `add_column` 算差额和增长率 `=(C2-B2)/B2`。
   - 条件统计：`SUMIFS` / `COUNTIFS` / `AVERAGEIFS`。
   - 跨表查找：`VLOOKUP(A2,[其他文件.xlsx]工作表!A:C,2,0)`（文件要在同一文件夹）。
4. **交付**
   - 汇总结果需要保留时，用 `summarize` 的 `save_as`，或 `create_spreadsheet` 生成新表（文件名写清内容，如「门店销售汇总_按区域.xlsx」）。
   - 让用户在屏幕上直接看到结果时，用 `filter_view` / `select_cells`。

## 回答格式

- 第一句给结论（最重要的 1–3 个数字），然后是支撑数字，最后是需要注意的问题（数据质量、口径）。
- 每个数字都来自工具结果；说清口径（例如“按‘实收金额’列合计，不含第 2 行的合计行”）。
- 数字保留合适的位数，金额加千位分隔，占比保留 1 位小数。

## 禁忌

- 不要心算、估算或“大约”；算不出来就说明原因。
- 不要逐行复述表格内容。
- 不要修改原文件；计算列只在屏幕上，需要留存就另存新文件。

# 表格核对对账

目标：给出**可追查的差异清单**——每一条差异都能定位到原表的哪一行，而不是一句“两表有出入”。

## 先确认三件事（从表里判断，判断不了再问用户）

1. **两份数据是哪两份**：当前表 + 同文件夹的另一个文件（用 `list_folder` 找），或同一文件的两个工作表。
2. **匹配键**：用哪一列把两边对上（订单号、门店编号、身份证号、商品编码……）。键列先用 `summarize` count 检查是否唯一；不唯一要先说明（可能需要“键 + 日期”组合）。
3. **比对列**：要比较哪些值（金额、数量、状态）以及容差（金额 ±0.01）。

## 核对步骤

1. 两边都 `sheet_overview`，记下各自的键列、比对列、数据行范围、合计。
2. **总数先对**：两边分别 `calculate` 行数和比对列合计（`COUNTA`、`SUM`）。总数一致也要继续逐条核对（可能相互抵消）。
3. **逐条匹配**（在当前表上加列，另一份文件写成 `[文件名.xlsx]工作表!A:Z`）：
   - 对方是否存在：`add_column` `=COUNTIF([对方.xlsx]Sheet1!A:A,A2)`，结果 0 = 对方缺失。
   - 取对方的值：`=IFERROR(VLOOKUP(A2,[对方.xlsx]Sheet1!A:F,4,0),"")`。
   - 差额：`=IF(F2="","",C2-F2)`；状态：`=IF(E2=0,"对方没有",IF(ABS(G2)>0.01,"金额不符","一致"))`。
   - 反方向也要做一遍（在对方表上，或用 `read_file` 读对方表后用 `COUNTIF` 反查），找出“只在对方表里有”的记录。
4. 用 `filter_view` 把状态不是“一致”的筛出来，`export_view` 导出差异明细；或把三类差异整理后用 `create_spreadsheet` 生成一份多工作表的核对结果：
   - 「核对结论」：两边行数、合计、一致条数、各类差异条数和金额。
   - 「本方有对方无」「对方有本方无」「金额不符」三张明细，保留键、两边的值、差额、原表行号。

## 回答格式

先给结论（一致 X 条，差异 Y 条，涉及金额 Z），再列最大的几笔差异，最后给出核对结果文件的位置和下一步建议（例如“这 3 笔疑似跨月入账，建议核对日期列”）。

## 禁忌

- 不要只比合计就下结论。
- 不要凭肉眼对比几行就说“基本一致”。
- 键有重复、格式不一（文本型数字 vs 数字、前后空格、全半角）时要先指出，必要时用 `TRIM`、`VALUE`、`TEXT` 统一后再比。
